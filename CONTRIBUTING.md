# Contributing

Please open an issue describing the observed behavior, expected behavior, OS, application version and browser before a large change. Pull requests should explain changes and validation; run `npm test`, `npm run build` and the relevant Rust tests.

Keep Windows and macOS behavior separate where required. Preserve backups, consent checks, directory validation and recovery behavior. Never include browser profiles, cookies, access tokens, local repair records or font backup files in an issue or pull request. Use synthetic fixtures.

Contributions are accepted under the repository MIT license. Third-party code and artwork must retain their original attribution and compatible licensing.
