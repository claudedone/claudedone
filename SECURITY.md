# Security

For issues involving credentials, unsafe command execution, unauthorized changes or unsafe recovery, use GitHub's private vulnerability reporting when enabled. If it is unavailable, contact the maintainers through the Telegram link in the README and request a private channel before sharing sensitive details.

Do not post credentials, real browser profiles, cookies, font backups or private repair logs in public issues. Include an affected version, OS, synthetic reproduction steps and the suspected impact. This project does not currently promise a response SLA or bug bounty.
